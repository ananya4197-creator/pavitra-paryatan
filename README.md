# Pavitra Paryatan

Pavitra Paryatan is a tourism website developed using HTML and CSS. The project aims to showcase famous pilgrimage destinations in India through a clean and user-friendly interface.

## Features

* Attractive design
* Information about pilgrimage destinations
* Easy navigation and image galleries
* Clean and modern user interface

## Technologies Used

* HTML5
* CSS3

## Purpose

This project was created to practice frontend web development skills and demonstrate the use of HTML and CSS in building a tourism-themed website.

## Future Improvements

* Add JavaScript for interactive features
* Include destination search functionality
* Improve responsiveness for all devices
